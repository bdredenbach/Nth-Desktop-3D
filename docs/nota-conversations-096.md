# Nth Nota conversations — 0.9.6

The Ask Nth Nota route now opens a dedicated native chat layout. It hides the settings preview and duplicate outer heading, uses an opaque dark glass conversation surface for readable text, and retains a settings/back route, conversation menu and close action. The welcome screen offers draft-only suggestions. The transcript scrolls independently from the composer, with separate user/assistant messages, selectable reply text, Copy and provider-supplied source links. Send becomes Stop during a request. The composer supports multiple lines and Android’s Send action.

The conversation menu includes New conversation, Recent conversations, Command examples, Undo last setting change, cloud-question settings and deletion of the current conversation with confirmation. Up to 12 conversations with 24 exchanges each stay on the device, in a separate preference file excluded from desktop backups and presets. Only the six most recent completed cloud exchanges, bounded to 9,000 content characters, become follow-up context. Local actions, refusals/errors and canceled replies do not become model context. Existing draft text remains local. New conversation starts without previous context.

Explicit launcher commands and app opening stay local. General explanations, writing, planning and comparisons go to the opted-in cloud assistant. Creative or explanatory mentions of settings must not execute the setting. Cloud prose never runs a device command. Consent-off requests do not create a transport. Stop, opting out, leaving the screen, closing or rotating cancel delivery and save a stopped state rather than accept a late reply.

The client checks a fixed `/v1/capabilities` endpoint only after Send and cloud opt-in. A chat-capable gateway receives the latest question, bounded conversation, search mode, timezone and launcher-setting reference values only for relevant launcher questions. It never receives Notes, cards or the installed app list. Capability detection does not send the question. An older gateway falls back to `/v1/write` with a bounded conversation prompt. Existing direct schedule lookup and Wikipedia-backed current-fact checks remain as limited legacy sources. The fallback cannot supply general live web search; that limitation is visible in the answer.

The paired Nth Nota backend change lives on the local `codex/nota-chat-gateway` branch in the Nth-Nota repository. It adds conversation-specific instructions, semantic search decisions, validated source IDs/quotes, and optional Cloudflare web-search integration. Writing/report/privacy routes and existing free-use caps remain. Search defaults off and requires explicit owner configuration; this work does not enable billing or deploy to Cloudflare. The model and source availability still limit accuracy. No token-streaming claim is made; visible status messages precede the complete response.
