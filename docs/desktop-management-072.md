# Desktop management — 0.7.2

Reference recordings: 226943.mp4 (desktop overview) and 226944.mp4 (Google session).

Hold empty desktop space or pinch two fingers together on empty space. Settings > Home screen > Manage desktops opens the same view. Swipe the 3D previews; tap one to open it. The house sets the default Home screen. Hold a preview and drag it over another to reorder; arrow buttons offer the same operation. The plus card adds an empty screen. Remove is enabled only for empty screens, and one screen always remains. Widgets, Scenes and Settings are available below the previews. Layout lock prevents management changes.

Previews draw saved app/folder layouts and widget regions without allocating or rebinding Android widget IDs. They show the selected scene artwork; they are miniatures, not separately active widget hosts. Screen movement preserves the original item lists, widget assignments, pattern flags, sorting Undo and Home selection.

Within a folder, hold an app and choose Move to folder under Add to folder. Choose a destination; its folder opens after the move. Moving preserves the selected shortcut and pinned metadata, checks destination capacity first, and avoids duplicate app placements. The current folder is excluded. Add to folder remains a copy operation.

Drawer/folder labels and menu titles show full names. Desktop icon labels retain the compact eight-character display. Full identity, search and accessibility remain unchanged. Native checks cover continuous screen drag, pinch, Home intent, metadata, protected nonempty screens, folder move/capacity/deduplication and long menu labels.
